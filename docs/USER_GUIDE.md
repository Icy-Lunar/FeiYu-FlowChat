# 肥鱼 FlowChat 使用教程

本教程面向第一次使用肥鱼 FlowChat 的用户，按“安装 → 配置模型 → 导入 → 续聊 → 备份”的顺序说明完整操作。

## 1. 使用前须知

肥鱼 FlowChat 是本地应用：Python 服务监听 `127.0.0.1`，浏览器通过 `localhost` 打开页面。对话数据默认保存在项目下的 `data/`，不会自动上传到肥鱼 FlowChat 的任何服务器。

以下操作会调用模型提供商，并可能产生费用：

- “测试 API（会计费）”；
- 正常发送消息；
- 导入对话时使用当前模型生成归档标题。

创建备份、搜索、整理、导入本地 JSON、查看历史版本等本地操作不会调用模型。

### 思考和联网按钮

保存模型配置并打开对话后，输入框底部可切换“思考”和“联网”。蓝色“开”表示启用，灰色“关”表示关闭；“未适配”可点击查看原因。联网允许模型按需检索，可能额外收费；思考可能增加 token 和等待时间。两个按钮的状态按模型档案记忆。

参数不兼容时，应用会在尚未开始输出的前提下回到默认模式重试一次，按钮随即显示“默认”，回复旁保留说明。默认模式由模型决定，有些模型仍会思考。余额、Key、限流或网络问题直接报错；已经收到文字或开始搜索的请求不会重放。可以再次点击按钮手动重新启用。

搜索返回的参考来源可在回复下方展开，随 JSON 一起保存。完整支持范围及回退规则见[思考、联网与回退](API_MODES.md)。

## 2. 安装与启动

### 2.1 环境要求

- Python 3.10 或更高版本；
- Windows 10/11 推荐使用 PowerShell；
- 能访问 DeepSeek 分享页及所选模型提供商的网络；
- 一个 OpenAI Chat Completions 兼容 API。Ollama 等本地服务可以不使用 API Key。

检查 Python：

```powershell
python --version
```

### 2.2 Windows 一键启动

在项目目录打开 PowerShell：

```powershell
.\run.ps1
```

脚本会完成以下工作：

1. 首次运行时创建 `.venv`；
2. 安装 `requirements.txt`；
3. 在 `127.0.0.1:8000` 启动服务；
4. 打开 <http://localhost:8000>。

如果 8000 端口被占用：

```powershell
.\run.ps1 -Port 8080
```

### 2.3 手动启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

不要把 `--host` 改成 `0.0.0.0`，除非你已经另外配置了用户认证、HTTPS 和网络访问控制。

### 2.4 把数据放到其他磁盘

在启动前设置 `FLOWCHAT_DATA_DIR`：

```powershell
$env:FLOWCHAT_DATA_DIR = "D:\FlowChatData"
.\run.ps1
```

环境变量只对当前 PowerShell 会话有效。迁移已有数据时，应先停止程序，再完整复制原 `data/` 目录。

## 3. 配置模型与 API

打开左下角“模型与 API 设置”。

| 字段 | 填写说明 |
| --- | --- |
| 配置档案 | 可以保存多个服务商或账号配置 |
| 档案名称 | 仅用于本地识别，例如“DeepSeek 工作账号” |
| 服务商预设 | 自动填充常见 Base URL 和模型初始值 |
| Base URL | API 根地址，也可直接填写以 `/chat/completions` 结尾的地址 |
| 模型 ID | 提供商实际接受的模型标识，不是界面显示名称 |
| API Key | 保存后进入操作系统凭据库，不写入 JSON 或备份 |
| Temperature | 越低通常越稳定，越高通常越发散 |
| 最大输出 Tokens | 留空时由提供商决定 |
| 系统提示词 | 每次请求时临时放在上下文开头，不写成历史消息 |
| 上下文范围 | “完整历史”或只发送最近 N 条消息 |

高级请求参数接受 JSON 对象，例如：

```json
{
  "enable_search": true
}
```

不要在高级请求头或请求体中填写不必要的密码、Cookie 或其他敏感凭据。

### 3.1 API 测试

点击“测试 API（会计费）”后，程序发送一条最多输出 16 tokens 的真实非流式请求。成功结果会显示服务商返回的模型、示例回复和可用的 token 用量。

测试请求不会写入对话归档，但提供商仍可能保存请求日志并正常计费。

### 3.2 获取模型列表

先保存配置档案，再点击“获取列表”。该功能请求兼容的 `/models` 接口。并非所有服务商都实现此接口；失败时仍可手动填写模型 ID。

### 3.3 API Key 保存方式

正常情况下，API Key 保存在操作系统凭据库。`data/provider_profiles.json` 只保存非敏感设置。

如果系统没有可用凭据库，页面会提示“Key 仅保留到程序关闭”。此时重启后需要重新输入 Key，备份也不会包含该 Key。

## 4. 导入 DeepSeek 历史对话

### 4.1 创建分享链接

在 DeepSeek 网页中打开目标对话并创建公开分享链接。链接格式应为：

```text
https://chat.deepseek.com/share/xxxxxxxx
```

分享链接本身相当于公开访问凭据。不要分享含密码、个人隐私、商业机密或其他敏感内容的对话。

### 4.2 单个导入

1. 点击“导入 DeepSeek 对话”；
2. 粘贴分享链接；
3. 点击“读取并归档”；
4. 等待对话出现在左侧归档列表。

导入时会保存两层数据：

- `data/archives/<对话 ID>.json`：便于续聊的 OpenAI 兼容归档；
- `data/raw/<对话 ID>.json`：DeepSeek 返回的完整原始响应。

归档会记录原始响应的 SHA-256，用于健康检查。

### 4.3 批量导入

在分享链接输入框中每行放一个链接。系统会去重后逐个导入，并汇总成功、重复和失败数量。单批最多接受 100 个链接。

### 4.4 标题生成规则

如果当前选择了可用的模型配置档案，导入后会额外发送一次短请求，让该模型根据对话内容生成具体标题。这次请求可能计费。

只有以下情况才会使用第一句用户消息作为备用标题：

- 没有选择模型档案；
- API Key 缺失；
- 服务商不可访问；
- 标题响应为空或格式不兼容。

标题旁的标记会显示“AI 标题”“手动标题”或“备用标题”。之后可以手动重命名。

### 4.5 重复链接

默认重复导入会打开已有归档，避免生成重复数据。API 还支持 `copy` 策略，可另存为副本；当前页面默认使用跳过策略。

## 5. 导入与导出 JSON

导入窗口切换到“OpenAI JSON”，可选择包含非空 `messages` 数组的 JSON 文件。单个文件最大 100 MB（包括内嵌附件）。

最小格式：

```json
{
  "title": "示例对话",
  "messages": [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"}
  ]
}
```

打开对话后点击“导出 JSON”，文件名会包含归档标题和 ID 前缀。API Key 永远不会进入导出的文件。

## 6. 继续对话

1. 打开一个归档或新建空白对话；
2. 确认输入框左下角显示正确的模型档案；
3. 输入消息并按 Enter；Shift+Enter 用于换行；
4. 模型回复会流式显示，完成后立即归档。

回复期间再次点击发送按钮可以停止生成。已经收到的部分回复会尽量保存，并标记为中断状态。

### 6.1 上下文范围

- 完整历史：把当前归档中的所有消息发送给模型；
- 最近消息：只发送最后 N 条，适合超长对话或控制费用。

输入区下方显示的是字符数换算出的粗略 token 估算，不代表提供商最终计费 token。

### 6.2 Markdown 与数学公式

消息会在显示时识别 Markdown，原始文本仍按原样保存并发送给模型。支持常见标题、粗体、斜体、删除线、链接、引用、列表、代码块和表格。

数学公式支持四种常见分隔符：

```markdown
行内公式：$E = mc^2$
行内公式：\(a^2 + b^2 = c^2\)

块级公式：
$$
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$

块级公式：
\[
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\]
```

围栏代码块和行内代码中的 `$`、反斜杠不会被当作公式。无法转换的 LaTeX 会以醒目的等宽文本回退显示，不会隐藏原消息。

Markdown/LaTeX 转换完全在本机完成，不会产生模型费用，也不会修改归档内容。

### 6.3 图片、OCR 和文件

导入 DeepSeek 分享后，附件显示在对应消息下，纯图片消息也会保留。

- **图片**：点击缩略图放大，点击下载保存副本。若来源不允许下载原图，仅保存预览图，会显示“预览副本已保存”；预览图可能与原图的尺寸、格式不同。
- **文档**：可以下载保存在本机的文件。PDF、DOCX、TXT、Markdown、CSV 等会尝试提取文字；展开“提取文字”查看。
- **OCR**：来源公开的 OCR 结果会保留，可搜索并参与后续对话。这里不会自动调用收费 OCR 服务，也不在本机重新识别扫描图片；没有文字层的图片/PDF 可交给支持相应输入的模型。
- **文件不可用**：未提供公开地址、签名过期、服务拒绝访问或超过大小限制时显示原因；对话和已有 OCR 文字仍然归档。

在“模型与 API 设置 → 续聊时如何发送附件”选择模型能力：

| 模式 | 发送内容 |
| --- | --- |
| 仅文字与 OCR / 提取文字（默认） | 消息正文、文件名和已取得的文字 |
| 文字与图片 | 上述文字及保存的图片；需要视觉模型 |
| 文字、图片与文件 | 上述内容及文件二进制；需要支持文件输入的接口 |

附件可能增加服务商计费；界面中的 token 估算只包含文字。模型不支持相应输入时，请切回文字模式。未取得识别文字的图片无法在文字模式下被理解。

自动下载每个文件最多 20 MB，每段对话合计最多 60 MB。只自动请求已验证的 DeepSeek 文件域名，不自动跟随重定向；其他来源的元信息仍保留。文档文字最多提取前 100 页 / 10 万字符；复杂排版可能失真，请以原文件为准。

附件字节内嵌在归档 JSON 中，所以 JSON 文件会增大；分享失效之后，已保存的副本仍能查看。全量备份也包含这些内容。旧版本已经导入的链接，可选择“重新读取为副本”来补全附件，原归档仍保留。

### 6.4 阅读与编辑

- 左侧可切换全部与收藏，按 `Ctrl+K`（Mac 为 `⌘K`）聚焦搜索。
- 顶部“•••”菜单提供整理、版本、重命名、导出与回收站操作，窄屏也可使用。
- 输入草稿按对话暂存在当前浏览器标签页的会话存储中；切换对话或刷新页面可恢复，关闭标签页后不保证保留。
- 回复期间向上滚动会暂停跟随，点击“回到最新消息”恢复。
- 消息复制保留原始 Markdown；代码块可以单独复制。

## 7. 整理与搜索

搜索框会匹配标题、文件夹、标签和全部消息正文。

每个对话支持：

- 收藏与置顶；
- 文件夹；
- 最多 20 个标签；
- 手动重命名；
- 批量整理；
- 批量移入回收站。

置顶对话优先显示，同一组内按最后更新时间排序。

## 8. 数据保全中心

### 8.1 历史版本

覆盖现有归档前，程序会先保存旧版本。每个对话最多保留 50 个版本。恢复旧版本之前，当前状态也会先成为一个版本，因此可以再次撤销。

### 8.2 回收站

普通删除只把归档移入 `data/archives/.trash/`。数据保全中心可以恢复或永久删除。

永久删除会清理对应的原始响应、版本和附件目录，无法恢复。

### 8.3 数据健康

健康检查会检查：

- 归档 JSON 是否可解析；
- `messages` 和 `message_metadata` 是否对齐；
- DeepSeek 原始响应是否存在；
- 原始响应 SHA-256 是否一致。

“扫描并修复”可以补齐元数据，并在存在可用历史版本时恢复损坏归档。无法自动修复的问题会保留并报告。

### 8.4 手动备份

点击“立即创建备份”后会生成 ZIP，并显示下载链接。备份包含：

- 当前归档和回收站；
- DeepSeek 原始响应；
- 历史版本；
- 附件目录；
- 不含 API Key 的模型配置；
- 备份与保留设置；
- 含文件大小和 SHA-256 的 `manifest.json`。

### 8.5 自动备份

建议把自动备份目录设置到另一块磁盘、NAS 同步目录或可靠的云盘同步目录。设置备份间隔、保留数量后勾选启用。

自动备份只在程序运行期间执行。页面会显示最近成功路径或最近失败原因。

### 8.6 恢复备份

恢复前会验证路径安全、ZIP CRC、格式版本、文件大小和 SHA-256。冲突策略：

| 策略 | 行为 | 适用情况 |
| --- | --- | --- |
| 跳过已有 | 保留当前同 ID 对话 | 日常合并，风险最低 |
| 另存副本 | 生成新 ID 和独立原始快照 | 想同时保留两份 |
| 保留版本后替换 | 当前归档先进入版本，再用备份替换 | 明确要回退到备份状态 |

备份不含 API Key。换电脑恢复后必须重新填写密钥。

## 9. 默认数据目录

```text
data/
├─ archives/                 当前归档
│  └─ .trash/               回收站
├─ raw/                      DeepSeek 原始响应
├─ versions/<对话 ID>/      历史版本
├─ attachments/             附件保留目录
├─ backups/                 页面创建的备份
├─ provider_profiles.json   不含密钥的模型档案
└─ settings.json            自动备份设置和状态
```

不要在程序运行期间手动编辑这些文件。如果确实需要修改，先创建完整备份并停止服务。

## 10. 常见问题

### 页面打不开

- 确认启动窗口没有报错；
- 访问脚本输出的端口；
- 尝试 <http://127.0.0.1:8000>；
- 端口冲突时使用 `run.ps1 -Port 8080`。

### 页面提示本地会话令牌无效

Python 服务重启后令牌会变化。刷新页面即可。

### DeepSeek 链接无法导入

- 确认链接是 `/share/`，而不是普通对话地址；
- 检查分享是否被删除或失效；
- 检查本机能否访问 `chat.deepseek.com`；
- 分享页面结构变化时，查看开发文档中的测试和调试方法。

### API 测试成功但聊天失败

- 检查模型 ID 是否真实存在；
- 检查上下文是否超过模型限制；
- 删除不兼容的额外请求参数；
- 降低最大输出 tokens；
- 查看服务商余额、速率限制和错误信息。

### 重启后 API Key 丢失

系统凭据库不可用时，Key 只能保存在进程内。安装或启用可用的系统 keyring 后重新保存，或者每次启动后重新填写。

### 自动备份没有运行

- 自动备份只在程序运行时执行；
- 确认目标目录存在或当前用户有创建权限；
- 查看“最近失败”信息；
- 先用“立即创建备份”验证基本备份链路。

## 11. 安全退出与迁移

在启动服务的 PowerShell 窗口按 `Ctrl+C`，等待出现应用关闭提示后再移动数据。

迁移到新电脑的推荐步骤：

1. 在旧电脑创建完整备份；
2. 在新电脑安装并启动肥鱼 FlowChat；
3. 在数据保全中心恢复 ZIP；
4. 重新填写每个模型档案的 API Key；
5. 执行数据健康检查；
6. 用一个非敏感问题验证聊天。
